## Design cues to translate into the website

| Cue | Interpretation for web |
| --- | --- |
| Sepia palm shadows | Use as soft decorative overlays on parchment or deep teal sections, never as literal illustrations. |
| Editorial collage rhythm | Alternate image-heavy and text-heavy sections with large breathing space and asymmetric balance. |
| Warm parchment + muted rose-gold typography | Keep linen/parchment base, use gold and deep teal as accents, avoid harsh contrast except in statement bands. |
| Transitional villa quote pages | Add short atmospheric pull-quote moments or framed statements rather than only functional content sections. |
| Brochure inspiration language | Build a new Inspiration section around "The island wrote the brief" and material/nature references. |
